2. 설치하기

1
관리자에게 받은 설치파일 다운로드: Windows .exe 또는 Mac .dmg
2
더블클릭해서 설치 진행 (일반 프로그램 설치와 동일)
3
설치 후 바탕화면/시작메뉴의 "이메일 AI 답장 도우미" 아이콘 실행
💡 Node.js, Python, VSCode 등은 전혀 설치하지 않아도 됩니다.

Ollama를 쓰실 경우에만 추가로

1
ollama.com에서 Ollama 설치
2
설치 후 터미널에서 한 번만: ollama pull llama3.1

3. 처음 실행하기 (순서대로 진행됨)

1
Gmail 로그인 — "Gmail로 로그인" 버튼 클릭 → 브라우저에서 본인 구글 계정 선택/로그인 → 권한 허용 (입력할 것 없음, 클릭만 하면 됨)
2
AI 모델 선택 — Ollama/Claude/GPT/Gemini 중 선택 후 필요한 키 입력 → 저장

두 단계가 끝나면 받은메일 화면이 열립니다.

4. 메일 확인하고 답장하기

1
왼쪽 목록에서 메일 클릭 → 오른쪽 읽기창에 원본 내용 표시
2
"✨ AI 답장 초안 생성" 버튼 클릭 → 분류/요약과 답장 초안이 나타남
3
초안을 직접 읽고 필요하면 수정
4
내용이 괜찮으면 "보내기" 클릭 → 실제로 발송됨
⚠️ "보내기"를 누르면 바로 실제 발송됩니다 (임시보관함이 아님). 발송 전 반드시 내용을 확인하세요.

5. 자주 묻는 질문

Q. 다시 분석하고 싶어요.

A. "다시 분석" 버튼을 누르면 같은 메일을 다시 분석해서 새 초안을 만듭니다.

Q. Outlook에서 메일을 보는데 왜 Gmail로 로그인하나요?

A. 실제 메일이 저장되는 곳이 Gmail 서버이기 때문입니다. Outlook은 그걸 보는 화면일 뿐이라, Gmail로 인증해서 처리하면 Outlook에서도 동일하게 반영됩니다.

Q. "확인되지 않은 앱" 경고가 뜨는데 계속해도 되나요?

A. 관리자가 회원님의 계정에 접근 권한을 미리 설정해뒀다면 "고급" → "이동" 클릭 후 진행하면 됩니다. 계속 뜬다면 관리자에게 문의하세요.

Q. 비용이 얼마나 드나요?

A. Ollama는 무료입니다. API 키 방식은 이메일 한 통 분석당 비용이 매우 적어서, 하루 수십~백 통을 처리해도 실제 청구 금액은 크지 않습니다.
