1. 개발 모드 실행

1
nodejs.org에서 LTS 버전 설치
2
터미널에서 프로젝트 폴더로 이동 후: 
npm install
npm run dev
Electron 창이 뜨면 성공입니다.

2. 배포용 설치파일 만들기

npm run dist:win    # Windows용 .exe → release/ 폴더
npm run dist:mac     # Mac용 .dmg (Mac에서 실행 필요)
💡 빌드 전에 반드시 electron/googleCredentials.ts를 채워야 합니다 (아래 3번 항목 참고). 안 채우고 빌드하면 사용자가 Gmail 로그인을 할 수 없습니다.

3. Google Cloud 설정 (Gmail 연동 준비, 최초 1회)

⚠️ Google Cloud Console이 최근 UI를 개편해서, 계정에 따라 화면 이름이 다르게 보일 수 있습니다. 아래 표를 참고하세요.
새 UI 이름옛 UI 이름 (화면에 이렇게 보일 수 있음)
Google 인증 플랫폼OAuth 동의 화면
클라이언트 (Clients)사용자 인증 정보

3-1. 프로젝트 생성 + Gmail API 활성화

1
console.cloud.google.com 접속
2
화면 맨 위 왼쪽 프로젝트 선택기 → "새 프로젝트" → 이름 입력 → 만들기 → 만든 프로젝트로 전환
3
왼쪽 ☰ 메뉴 → API 및 서비스 → 라이브러리 → Gmail API 검색 → 클릭 → "사용"

3-2. OAuth 동의 화면(Google 인증 플랫폼) 설정

1
왼쪽 메뉴 → API 및 서비스 → "OAuth 동의 화면"(= Google 인증 플랫폼) 클릭
2
사용자 유형을 확인합니다 (좌측 메뉴의 "대상" 탭에서 확인 가능):
사용자 유형의미다음 단계
내부회사 Google Workspace 조직(예: @회사도메인) 계정만 사용, 자동 허용테스트 사용자 등록 불필요 → 3-3 생략, 바로 3-4로
외부개인 Gmail 등 조직 밖 계정도 포함 가능테스트 사용자를 직접 등록해야 함 (아래 3-3)
💡 동료들이 전부 회사 Google Workspace 계정(예: @회사도메인.com)을 쓴다면 "내부"가 더 편합니다. 100명 제한도 없고 테스트 사용자를 한 명씩 등록할 필요도 없습니다. "외부로 설정" 버튼은 누르지 마세요.

3-3. 테스트 사용자 등록 (사용자 유형이 "외부"인 경우만)

1
"OAuth 동의 화면" 페이지에서 "테스트 사용자" 항목까지 스크롤
2
"사용자 추가" 클릭 → 실제로 쓸 동료들의 Gmail 주소를 한 명씩 입력 → 저장

3-4. OAuth 클라이언트 ID 발급

1
왼쪽 메뉴 → "사용자 인증 정보" (새 UI에서는 "클라이언트") 클릭
2
"+ 사용자 인증 정보 만들기" (또는 "+ 클라이언트 만들기") → "OAuth 클라이언트 ID" 선택
3
애플리케이션 유형: "데스크톱 앱" 선택 → 이름 입력 (예: 이메일AI답장도우미) → "만들기"
4
화면에 표시되는 클라이언트 ID / 클라이언트 보안 비밀번호를 바로 복사해두세요 (보안 비밀번호는 나중에 다시 확인이 어려울 수 있습니다)

3-5. 코드에 붙여넣기

electron/googleCredentials.ts 파일을 열어서:

export const GOOGLE_CLIENT_ID = "복사한 클라이언트 ID";
export const GOOGLE_CLIENT_SECRET = "복사한 클라이언트 보안 비밀번호";

저장 후 이 상태로 npm run dist:win / dist:mac으로 빌드하면 값이 설치파일에 포함됩니다. 사용자는 이 값을 절대 입력하지 않고, "Gmail로 로그인" 버튼만 누르면 됩니다.

4. 새 AI 모델 추가하는 법

  1. electron/providers/새모델.ts에 AIProvider 인터페이스 구현
  2. electron/providers/index.ts의 getProvider()에 case 추가
  3. electron/providers/types.ts의 ProviderId/ProviderSettings에 타입 추가
  4. src/Settings.tsx에 선택 옵션 추가

5. 문제 해결

증상원인/해결
electron 명령을 찾을 수 없음node_modules 삭제 후 npm install 재시도
Gmail 인증 창이 안 열림방화벽이 localhost:8721 차단 → 예외 추가
"확인되지 않은 앱" 경고사용자 유형이 "외부"인데 그 계정이 테스트 사용자로 등록 안 됨 → 3-3 진행, 또는 "내부"로 전환 검토
Client ID 관련 에러로 로그인 실패electron/googleCredentials.ts를 채우지 않고 빌드했을 가능성 → 값 채운 뒤 재빌드
